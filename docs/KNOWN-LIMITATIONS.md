# 当前版本边界

- 本次是独立测试环境；历史数据和 ERP 账套来自演练副本，原系统入口继续运行。正式切换尚未执行。
- 目前使用同源 Cookie 会话集成内部系统，没有实现第三方 OIDC / OAuth 登录，也没有实现 SaaS 多组织租户。
- 账号恢复由平台管理员重置密码并强制用户换密；未接入邮件/短信找回密码或多因素认证。已有迁移账号的密码保持兼容，新建及重置账号才要求首次换密。
- 默认测试入口使用 HTTP。正式使用前应配置域名、TLS 和 Secure Cookie；账号密码、ERP 密钥只保存在私有配置和加密数据中。
- PDF 文本解析、CSV / Excel 银行流水解析已验证。扫描件 OCR 未配置供应商；云端模型默认关闭。不能把自动建议当成已经审核的账务。
- 第二子应用是接入样例，没有采购、库存等新增业务。
- 主要用户路径已在桌面 Edge / Chromium 验证；移动端完整导航与交互尚未验收。
- 开账连接失败可使用相同请求重试；如果进程在开账处理中被强制终止，PROVISIONING 状态目前需要维护人员核对并恢复，没有自动过期租约。
- 首次部署及回滚会短暂重启应用，不是零停机发布。数据库破坏性迁移不在本期范围内；回滚工具拒绝不同 schema 的自动切换。
- 完整财务验收基于受控虚构公司和真实 ERPNext 服务，不代表完成新增税务合规、银行直连或生产容量认证。
