# 合一工作台使用说明

## 1. 登录和选择公司

打开交付的测试地址，输入平台账号和密码。顶部选择当前公司，左侧进入“财务工作台”或“集成示例”。每个账号只显示获授权的公司和应用。

新建账号或管理员重置密码后，先输入当前密码并设置至少 12 个字符的新密码，两次新密码须一致。换密完成后重新登录；此前打开的业务页面会在授权允许时恢复。

右上角点击姓名 → **账号安全**，可以修改密码、查看登录设备、退出指定设备或退出其他设备。密码修改会退出所有设备；一个账号最多保留 10 个登录。退出登录会同步到同一浏览器的其他工作台标签页。

切换公司会切换整页业务数据。正在编辑单据时，系统会询问是否放弃编辑；选择留下会保留当前内容。

## 2. 财务日常流程

1. 进入“单据与审核”，上传 PDF、银行 CSV / Excel，或点击“手工录入”。
2. 打开单据，对照原件填写日期、交易对手、金额、科目和借贷分录。解析结果只是建议，必须人工检查。
3. 保存审核结果，生成 ERP 草稿。草稿尚未形成正式账务。
4. 有正式提交权限的人员核对后确认提交。已提交单据会显示 ERP 凭证编号，可在“会计凭证”和“财务报表”核对。

文件内容相同会提示重复；同账套的发票号码也会查重。借贷不平衡、科目不属于当前公司或期间已锁定时不能生成草稿。

## 3. 项目、流水和报表

- **项目与合同**：登记合同额和预算，将单据分录关联到项目，查看项目收入、成本、收款和付款。利润与现金结余分别计算。
- **银行流水**：上传银行 CSV / Excel 后到此逐条核对，匹配已提交的 ERP 凭证。银行批次文件本身不整批入账。
- **会计凭证**：查询草稿及已提交凭证。
- **财务报表**：查看资产负债表、利润表、总账、应收和应付；数据来自当前账套的 ERPNext。
- **操作日志**：查看审核修改、提交等记录。

## 4. 管理账号和权限

平台管理员在左侧“平台管理”中维护用户、公司、应用、角色和授权。先给用户加入公司，再授予这个公司内的业务角色。

平台管理权限与财务权限分别授予。能维护用户不代表能查看或提交财务；只读角色不能审核或正式提交。撤销授权后下一次请求即受限制。

用户管理支持重置密码、解除账号登录限制、退出全部设备及停用账号。只持有用户维护权限的人员不能修改权限超出自己范围的账号；需要由授权管理员处理。已分配角色的权限和启用状态也需要授权管理权限，防止通过编辑角色扩大自身权限。系统始终保留至少一位具备完整平台管理权限的有效管理员。

成员授权页面的“实际生效权限”按应用和公司展示结果。**移除公司成员资格会同时撤销该公司的全部角色**，重新加入公司后需要重新授权。停用公司、角色或应用属于临时停用，重新启用后仍保留原分配关系。

当前公司没有授权的应用不会显示。权限变更在服务端下次请求即生效；界面在切回窗口、手动刷新权限或最多 30 秒的检查后更新，本浏览器中做的授权操作也会通知其他标签页。

未开账的公司可在财务“账套配置”中连接本测试环境允许的账套。公司 ID 与账套 ID 是内部映射，不需要用户手工修改。

## 5. 遇到问题

- 应用暂时打不开：点击“重新打开”，也可先去其他应用。
- 登录过期：重新登录；改密码或管理员停用账号会使已有登录失效。
- 忘记密码：联系平台管理员重置。此版不发送邮件或短信重置链接。
- 连续输错密码：15 分钟内同账号最多尝试 10 次；可以等待限制到期或由管理员解除账号限制。同一来源地址也有限制，管理员解除账号限制不会取消来源限制。
- 没看到公司或按钮：先核对当前公司，再由平台管理员检查角色授权。
- 单据解析失败：查看原因并重试或人工录入。扫描件 OCR 和云端 AI 需要另行配置供应商，默认没有开启。
- 正式提交遇到网络中断：刷新单据再重试，系统会按原单据引用查找已有凭证；不要重新建一张相同单据。

本次交付为隔离测试环境。演练账套与原系统独立，正式切换安排见 `MIGRATION.md`。
